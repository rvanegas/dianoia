+# StaleResultsPropagation System Implementation
+
+## Overview
+
+The StaleResultsPropagation system has been successfully implemented to enable agents to work with the most recent relevant results for any given conversation and snapshot, without needing to copy or mark results as stale.
+
+## Key Features Implemented
+
+### 1. Enhanced AgentResult Structure
+
+**File**: `backend/services/agents.py`
+
+- Added new fields to `AgentResult` dataclass:
+  - `conversation_id: str` - Links result to specific conversation
+  - `snapshot_id: str` - Links result to specific snapshot
+  - `task_data: Dict[str, Any]` - Stores target_type and target_content
+
+- All agents now properly set these fields when creating results:
+  - **ContentEvaluationAgent**: `target_type='argument'` (evaluates entire argument)
+  - **FormEvaluationAgent**: `target_type='argument'` (evaluates entire argument)
+  - **FormalizationAgent**: `target_type='proposition'` with `target_content=proposition_text`
+  - **ArgumentBuilderAgent**: `target_type='proposition'` with `target_content=proposition_text`
+  - **RewriterAgent**: `target_type='proposition'` with `target_content=proposition_text`
+
+### 2. AgentCoordinator Enhancements
+
+**File**: `backend/services/agent_coordinator.py`
+
+#### New Methods Added:
+
+- `getLatestResults(conversation_id, snapshot_id)` - Retrieves latest results for a snapshot
+- `_get_latest_result(...)` - Helper method for getting specific latest results
+- `get_all_agent_types()` - Returns list of all available agent types
+- `get_propositions_in_snapshot(...)` - Extracts propositions from snapshot
+- `create_agent_input(...)` - Creates agent input with latest results context
+- `create_agent_result(...)` - Helper method for creating properly structured results
+
+#### Enhanced Task Processing:
+
+- Updated `_process_task()` to include new fields in task results
+- Results now include `conversation_id`, `snapshot_id`, and `task_data`
+
+### 3. AgentInput Schema Updates
+
+**File**: `backend/schemas/agent_input.py`
+
+- Added `latest_results: List[Dict[str, Any]] = []` field to `AgentInput`
+- Maintains backward compatibility with default empty list
+
+## Core Functionality
+
+### Result Filtering by Target Type
+
+The system distinguishes between two types of results:
+
+1. **Argument-level results** (`target_type='argument'`)
+   - Apply to the entire argument as a whole
+   - Examples: Content evaluation, formal evaluation
+
+2. **Proposition-level results** (`target_type='proposition'`)
+   - Apply to specific propositions within the argument
+   - Examples: Formalization, rewriting, building
+
+### Snapshot-Aware Result Retrieval
+
+- Results are filtered by `snapshot_id` (only results ≤ current snapshot)
+- Latest results are determined by highest `snapshot_id` for each agent type/target combination
+- No future results are included (maintains temporal consistency)
+
+### Backward Compatibility
+
+- Existing code continues to work without modification
+- New fields have sensible defaults
+- Result manager handles both old and new result formats
+- Graceful degradation when new fields are missing
+
