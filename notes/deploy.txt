
Deployment Recipe:

Create Lightsail instance
Ubuntu 22.04 LTS
lightsail-ubuntu ssh key

Networking / Attach static IP
Add ipv4 rule for tcp/8000

sudo apt update
sudo apt upgrade -y
sudo apt install docker.io docker-compose git emacs -y
sudo usermod -aG docker $USER
sudo reboot

scp gh keys and config to server
git clone git@github.com:rvanegas/dianoia.git

add dianoia/bin to bash PATH
copy OPENAI_ID to backend/.env
set VITE_API_BASE_URL in frontend/.env to blank

hard reset:
docker-compose down --volumes --remove-orphans
docker-compose build --no-cache
docker-compose up -d

For simple deployment, see 'bin/deploy'.

SSL Recipe:

Add ipv4 ryle for tcp/https/443

sudo apt install certbot python3-certbot-nginx -y

docker run --rm -p 80:80 \
  -v /etc/letsencrypt:/etc/letsencrypt \
  -v /var/lib/letsencrypt:/var/lib/letsencrypt \
  certbot/certbot certonly --standalone \
  --non-interactive --agree-tos \
  -m rvanegas@gmail.com -d dianoia.rvanegas.com
