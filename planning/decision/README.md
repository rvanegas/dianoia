# Decisions

What was built and why, including what was deliberately not built. History,
not work: read it when something in the code is inexplicable and knowing why
would change what you do, matching filenames first. One file per decision,
named `<date>-<slug>.md`; `ts note new decision "Some Title"` makes one.

`archive/` holds what `notes/` held until 2026-11-06, frozen: the 2025 plans
for the agents (architecture, rearchitecture, results by snapshot, the
improvement agent, input normalization), and the first Lightsail deploy and
development recipes, which `ts deploy` and `DOCKER_ARCH.md` replaced. Match
filenames first; never sweep the prose.
